§1 Executive Summary（執行摘要）

結論：觀望 / 估值便宜但需要催化劑確認

新秀丽FY2025收入跌2.5%，但市場更關注利潤端的下滑——調整淨利潤跌20.7%至USD 293M，毛利率受美國關稅和促銷活動擠壓降40bps至59.6%。然而Q4已出現明顯復甦信號：收入反彈+2.2%、毛利率回升至60.3%、自由現金流按年增長25.7%。

四個 gate 評估： - Gate 1（業務質量）：✅ 全球最大行李箱品牌，TUMI高端定位清晰，DTC渠道升至41.7% - Gate 2（問題診斷）：⚠️ 關稅/促銷壓力——暫時性；消費者情緒——恢復中；結構性問題輕微 - Gate 3（資產負債表）：✅ 净債務/EBITDA 1.8x，現金USD 649M，生存能力無虞 - Gate 4（估值差距）：✅ 現價HKD 14.24，PB 1.66x（低端），PE 9.9x（過去5年中位以下），股息率~5%

核心催化劑： 2026年美國雙重上市——如成功，估值或向15-18x PE重估 最大風險： 宏觀消費持續疲弱 + 關稅升級 + 雙重上市延遲 現時判斷： 估值進入價值區，但宏觀逆風未完全消退，適合分注吸納而非一次過重倉

§3 What the Market is Worried About（市場擔憂因素）

1. 宏觀消費疲弱（暫時性） - 亞洲：南韓-9%、中國-2.6%，主因消費者信心不足 - 北美：實體批發客戶採購審慎，入境旅遊減少 - 中東地緣政治影響長途旅遊需求

2. 美國關稅壓力（暫時性 / 已有對沖） - FY2025毛利率降至59.6%（2024年：60.0%） - 公司已實施關稅緩和措施 + 採購規模優勢 - DTC渠道和高毛利率地區組合抵消部分影響

3. 促銷活動增加（暫時性） - 需求疲弱下增加策略性促銷以支撐銷售 - Q4毛利率已反彈至60.3%，顯示促銷壓力正在消退

4. 雙重上市延遲擔憂（結構性中性） - 2024年3月宣佈 → 2026年3月股東批准 → 目標2026年完成 - 股價因此受壓（年初至今跌~28%） - 延遲或稀釋效應是主要風險

5. 管理層變動（過渡性） - Chairman Tim Parker 退休（2026年） - 新CFO Thomas R. Pizzuti（KPMG背景）已於2026年2月履新

6. 派息不確定性（已澄清） - 市場曾擔心削減派息 - FY2025末期息 USD 0.1009，中期息 USD 0.1009，全年 USD 0.2018，派息比率~45%
